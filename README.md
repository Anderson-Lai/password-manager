# Password-Manager

Password-Manager is a fully local and open-source password manager written in Rust.

## Building

**Note: ensure you already have cargo installed**  

``` sh
cargo build --release
```

The binary will be found in ${PROJECT_ROOT}/target/release/

## Commands

For a list of all available commands, run the following command:  

``` sh
./password_manager help
```
